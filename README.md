## 🚀 Featured Projects

### 🤖 AI & Agentic Systems

#### [Git RAG — Agentic GitHub Repository Assistant](https://github.com/DEV1767)
> Understand and query any GitHub repository using an agentic RAG pipeline.

- Repository ingestion and code-aware **chunking**
- **Hybrid retrieval** with **reranking** for more accurate context
- **MCP-based tool execution** orchestrated through LangGraph agents


**Stack:** `Python` `LangGraph` `LangChain` `MCP` `Qdrant` `FastAPI` `Groq`

---

#### [AI Commander — VS Code AI Agent(https://github.com/DEV1767/Ai-Commander)

> Debugging help that lives inside your editor.

- Captures **terminal errors** directly from the developer workflow
- Uses an **agentic workflow** to generate context-aware debugging guidance
- Delivered as a VS Code extension backed by Node.js and FastAPI services

**Stack:** `TypeScript` `VS Code Extension API` `Node.js` `Express` `FastAPI` `LangGraph` `MongoDB` `LLM APIs`

---

### ⚙️ Backend Engineering

#### [EventHub — College Event Management Platform](https://github.com/DEV1767/eduhub-backend)
> Production-ready backend for college events, built for 1,000+ concurrent users.

- **Role-based access control** with **JWT** authentication
- Validated REST APIs (Joi) with consistent error handling
- **Redis caching** for performance at scale

**Stack:** `Node.js` `Express` `MongoDB` `Mongoose` `Redis` `JWT` `Joi`

---

#### [URL Shortener Backend](https://github.com/DEV1767/Urlshortner_backend)
> Secure URL shortening service with user accounts.

- User authentication with **JWT-based authorization**
