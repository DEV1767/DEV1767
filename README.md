### 🤖 AI & Agentic Systems

#### [Git RAG — Agentic GitHub Repository Assistant](https://github.com/DEV1767)
Understand and query GitHub repositories with an agentic RAG pipeline.

- Repository ingestion and code chunking
- Hybrid retrieval with reranking
- MCP-based tool execution

**Stack:** `Python` `LangGraph` `LangChain` `MCP` `Qdrant` `FastAPI` `Groq`

#### [AI Commander — VS Code AI Agent](https://github.com/DEV1767/Ai-Commander)
Debugging help that lives inside your editor.

- Captures terminal errors from the developer workflow
- Agentic workflow generates context-aware debugging guidance
- VS Code extension backed by Node.js and FastAPI services

**Stack:** `TypeScript` `VS Code Extension API` `Node.js` `Express` `FastAPI` `LangGraph` `MongoDB` `LLM APIs`

### ⚙️ Backend Engineering

#### [EventHub — College Event Management Platform](https://github.com/DEV1767/eduhub-backend)
Production-ready backend for college events, supporting 1,000+ concurrent users.

- Role-based access control with JWT authentication
- Validated REST APIs using Joi
- Redis caching for performance

**Stack:** `Node.js` `Express` `MongoDB` `Mongoose` `Redis` `JWT` `Joi`

#### [URL Shortener Backend](https://github.com/DEV1767/Urlshortner_backend)
Backend service for creating shortened URLs with user accounts.

- JWT-based authentication and authorization
- MongoDB persistence
- Automatic redirection to the original URL

**Stack:** `Node.js` `Express` `MongoDB` `JWT`
